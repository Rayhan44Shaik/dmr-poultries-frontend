# DMR Poultries Web (frontend)

React + TypeScript + Vite + Electron UI for DMR Poultries ERP.

Monorepo path: `DMR-Poultries-ERP/frontend/dmr-poultries-web/`

## Develop

From repo root:

```bash
npm run frontend:install
npm run frontend:dev
```

From this folder:

```bash
npm install
npm run dev
```

Backend API (separate package): see `../../backend/README.md` or run `npm run backend:dev` from the repo root.
